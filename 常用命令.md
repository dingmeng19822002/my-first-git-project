# Git 常用命令速查

## 基础操作
```bash
git init                # 初始化仓库
git status              # 查看状态
git add <file>          # 添加文件到暂存区
git commit -m "message" # 提交
git log                 # 查看历史
```

## 分支操作
```bash
git branch              # 查看分支
git branch <name>       # 创建分支
git switch <name>       # 切换分支
git merge <name>        # 合并分支
git branch -d <name>    # 删除分支
```

## 远程操作
```bash
git remote add origin <url>  # 添加远程仓库
git push -u origin main      # 推送到远程
git pull                     # 拉取更新
```
